# 🧩 Customer Segmentation using K-Means Clustering

## 📘 Overview
This project applies **K-Means Clustering** to perform **customer segmentation** based on their **Annual Income** and **Spending Score**.  
It helps identify groups of customers with similar purchasing behavior, which is useful for targeted marketing strategies and business insights.

---

## 🧠 Key Features
- Data preprocessing and encoding categorical data  
- Finding optimal number of clusters using **Elbow Method**  
- Applying **K-Means** algorithm for clustering  
- 2D and 3D visualization of customer groups  
- Cluster summary for better interpretation of results  

---

## 🧩 Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  
- Google Colab  

---

## 📂 Dataset
The dataset used is **Mall Customer Segmentation Data** (`Mall_Customers.csv`).  
It contains demographic and spending information of mall customers.

**Dataset Columns:**
- `CustomerID` — Unique ID for each customer  
- `Gender` — Male/Female  
- `Age` — Age of the customer  
- `Annual Income (k$)` — Annual income in thousand dollars  
- `Spending Score (1-100)` — Score assigned by the mall based on customer spending
